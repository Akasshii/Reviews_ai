# 🚀 Быстрый старт - Reviews AI

## Запуск проекта

### 1. Установка зависимостей

```bash
cd frontend
npm install
```

### 2. Запуск dev сервера

```bash
npm run dev
```

Приложение будет доступно по адресу: http://localhost:5173/

### 3. Вход в систему

На странице логина используйте **любой email и пароль** для входа (demo режим).

## 📱 Основные функции

### Dashboard (Главная)
- Общая статистика по отзывам
- Средний рейтинг
- Распределение оценок
- Последние отзывы
- Последние отчеты

### Отчеты
- Просмотр всех отчетов
- Фильтрация по платформам (Все / Яндекс / 2ГИС)
- Создание нового отчета
- Выбор периода и платформы для анализа

### Профиль
- Просмотр информации о пользователе
- Редактирование данных
- Статистика аккаунта

### Настройки
- Управление безопасностью
- API ключи для платформ
- Настройка уведомлений
- Email рассылки

## 🎨 Особенности UI

- **Адаптивный дизайн** - работает на всех устройствах
- **Современный интерфейс** - градиенты, тени, анимации
- **Интуитивная навигация** - боковое меню с активными состояниями
- **Красивые карточки** - с hover эффектами

## 📊 Mock данные

Приложение использует заглушки для демонстрации:
- 425 отзывов
- 3 готовых отчета
- Статистика по рейтингам
- Последние отзывы с сентимент-анализом

## 🏗 Архитектура FSD

```
app/        - инициализация приложения, роутинг, layouts
pages/      - страницы приложения
widgets/    - сложные UI блоки (header, sidebar)
features/   - функциональность (auth, генерация отчетов)
entities/   - бизнес-сущности (user, report, review)
shared/     - переиспользуемые компоненты и утилиты
```
