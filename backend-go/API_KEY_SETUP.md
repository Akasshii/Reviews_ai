# 🔑 Настройка OpenRouter API ключа

Для работы AI анализа отзывов необходимо получить и настроить API ключ от OpenRouter.

---

## Шаг 1: Получение API ключа

1. Перейдите на https://openrouter.ai/
2. Нажмите **"Sign In"** в правом верхнем углу
3. Войдите через Google/GitHub или создайте аккаунт
4. После входа нажмите на ваш аватар → **"Keys"**
5. Нажмите **"Create Key"**
6. Дайте ключу название (например "Reviews AI")
7. Скопируйте созданный ключ (он начинается с `sk-or-v1-...`)

**Важно:** Сохраните ключ в безопасном месте, он больше не отобразится!

---

## Шаг 2: Вставка ключа в проект

### Вариант 1: Через .env файл (рекомендуется)

Откройте файл `backend-go/.env` и найдите строку:

```env
OPENROUTER_API_KEY=your-openrouter-api-key-here
```

Замените `your-openrouter-api-key-here` на ваш реальный ключ:

```env
OPENROUTER_API_KEY=sk-or-v1-ваш-реальный-ключ-здесь
```

### Вариант 2: Через переменную окружения

```bash
export OPENROUTER_API_KEY="sk-or-v1-ваш-реальный-ключ"
go run cmd/api/main.go
```

---

## Шаг 3: Проверка работы

1. Запустите backend:
   ```bash
   cd backend-go
   go run cmd/api/main.go
   ```

2. Создайте отчёт через frontend

3. Проверьте логи backend - если ключ работает, вы увидите успешный AI анализ

## 🎯 Используемая модель

По умолчанию используется модель **qwen/qwen3-coder:free** - это:

✅ **Бесплатная модель**
✅ **Хорошее качество анализа**
✅ **Поддержка русского языка**
⚠️ **Есть лимиты на количество запросов**

Если нужна другая модель, измените в `.env`:

```env
OPENROUTER_MODEL=anthropic/claude-3-haiku
# или
OPENROUTER_MODEL=openai/gpt-3.5-turbo
```

Полный список моделей: https://openrouter.ai/models

## 🔍 Troubleshooting

### Ошибка "API error: 401"

- Проверьте что ключ вставлен правильно
- Убедитесь что нет лишних пробелов
- Проверьте что ключ начинается с `sk-or-v1-`

### Ошибка "API error: 403"

- У вас закончились бесплатные credits
- Пополните баланс на https://openrouter.ai/

### Ошибка "API error: 429"

- Превышен лимит запросов
- Подождите несколько минут
- Или используйте платную модель

### AI анализ не работает

Система будет работать с **базовым анализом** если:
- API ключ не установлен
- Нет интернета
- OpenRouter недоступен

Базовый анализ включает:
- Подсчёт статистики
- Определение sentiment
- Извлечение категорий
- Но без AI insights и recommendations

3. Регулярно обновляйте ключи для безопасности
